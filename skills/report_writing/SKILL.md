# Report Writing Skill

## Structure
1. Title
2. Executive summary
3. Research question and scope
4. Methodology
5. Key findings
6. Detailed analysis
7. Limitations and uncertainties
8. Conclusion
9. References

## Style
- Use concise, neutral professional language.
- Use descriptive headings and short paragraphs.
- Attach source URLs to claims.
- Distinguish source-backed findings from analysis.
- Do not create references that were not supplied.
